# Security Policy — GravityPivot

GravityPivot is a proprietary browser game. The public repository does not include a security support SLA, bug bounty, or commitment to provide fixes. Licensing status does not determine whether a defect is a security vulnerability.

## Reporting

If you find a security concern, use GitHub's private vulnerability reporting for this repository if it is available. Otherwise contact the owner through the [GitHub profile](https://github.com/gthgomez). Please avoid publishing exploit details or personal data in a public issue. Reports are welcome, but there is no guaranteed response time or remediation commitment.

## Scope

The game runs client-side and stores progression in the player's local browser storage. It has no game server, accounts, or hosted player database. Client-side code and dependencies can still have security defects; this description is not a security guarantee.

Third-party components remain subject to their own licenses and security policies.
