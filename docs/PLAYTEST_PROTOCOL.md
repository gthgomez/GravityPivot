# First-session playtest

Use this short script with five people who have not played GravityPivot. Do not explain the controls before the first attempt. Ask them to think aloud, but do not coach during the first 30 seconds.

1. Start a Standard run and play naturally for up to one minute.
2. After the first run, ask: “What caused that run to end?”, “What would you try differently?”, and “Would you play again?”
3. Let them retry once. Note whether they discover hold → orbit → release without help.
